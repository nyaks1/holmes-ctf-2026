# F1: HTB flag format conventions
## Findings
### [1] HTB CTF event flags most commonly use HTB{XXXXXX}, but official docs explicitly allow non-braced forms
- quote: "Flags can take multiple different formats: The most common flag format is `HTB{XXXXXX}`. Depending on the specific challenge, the flag might also be a date, a name, an IP address, or a CVE number."
- url: https://help.hackthebox.com/en/articles/5200851-ctf-user-s-guide
- source_type: primary
- published: Updated yesterday (as of 2026-09-17 fetch; article by Ryan Gordon)
- confidence: high
### [2] HTB Labs Challenges (non-event) require HTB{...} unless the challenge description says otherwise
- quote: "Input the flag into the submission text box. Flags will always be in the exact format `HTB{s0m3_t3xt}` unless strictly specified otherwise in the Challenge description."
- url: https://help.hackthebox.com/en/articles/5185436-how-to-play-challenges
- source_type: primary
- published: Updated yesterday (as of 2026-09-17 fetch; article by Fischer)
- confidence: high
### [3] Official HTB Labs Sherlocks are question/answer investigations, not single flag-string submissions
- quote: "Answer the Tasks: You will be presented with a series of mandatory questions related to the scenario. Submit your answers directly on the HackTheBox platform to solve the investigation. ... Once all answers are correctly submitted, you complete the Sherlock."
- url: https://help.hackthebox.com/en/articles/8570249-how-to-play-sherlocks
- source_type: primary
- published: Updated yesterday (as of 2026-09-17 fetch; article by Diablo)
- confidence: high
### [4] Sherlock UI on Labs uses a Play Sherlock panel for answer submission; modes are Linear vs Free-flow questions
- quote: "Play Sherlock: This is the main page that allows you to actively engage with the challenge and submit your answers. ... Linear: Answering an investigatory question successfully unlocks the next. Free-flow: All investigatory questions are available to answer in any order you like."
- url: https://help.hackthebox.com/en/articles/8570249-how-to-play-sherlocks
- source_type: primary
- published: Updated yesterday (as of 2026-09-17 fetch; article by Diablo)
- confidence: high
### [5] Sherlock author requirements mandate a clear list of questions; no flag-wrapping format is specified for answers
- quote: "You must provide a clear list of questions for HTB users to solve throughout the investigation process."
- url: https://help.hackthebox.com/en/articles/8463668-sherlocks-submission-requirements
- source_type: primary
- published: June 11, 2026
- confidence: high
### [6] CTF event Challenges submit flags into a challenge-card field; multi-flag challenges exist (checkpoints + completion)
- quote: "To submit the flag, paste it into the submission field on the challenge card and click the arrow icon. ... For Challenges that contain multiple flags, XP distribution follows the catalogue below: XP for Checkpoints (only used on CTFs) ... XP for Completion"
- url: https://help.hackthebox.com/en/articles/5200851-ctf-user-s-guide
- source_type: primary
- published: Updated yesterday (as of 2026-09-17 fetch; article by Ryan Gordon)
- confidence: high
### [7] Archive passwords differ by content type: Challenges/machines use hackthebox; Sherlock investigation packages use hacktheblue
- quote: "Enter the password `hackthebox` to extract the files successfully" (Challenges); "The password to extract this file is always \"hacktheblue\"." (Sherlocks)
- url: https://help.hackthebox.com/en/articles/5185436-how-to-play-challenges ; https://help.hackthebox.com/en/articles/8570249-how-to-play-sherlocks
- source_type: primary
- published: Updated yesterday (as of 2026-09-17 fetch)
- confidence: high
### [8] Official docs do not document a "Submit flag + Flags N/M, no questions" Sherlock/event hybrid UI
- quote: Official help center articles describe either (a) Labs Sherlocks with mandatory questions and answer submission, or (b) CTF event Challenges/Machines with a single flag paste field; no fetched article documents a Sherlock UI that shows only "Submit flag" and a Flags 0/10 counter with zero listed questions.
- url: https://help.hackthebox.com/en/collections/2919917-htb-labs-community-platform ; https://help.hackthebox.com/en/collections/2919931-htb-ctf-ctf-platform
- source_type: primary
- published: Collection indexes fetched 2026-09-17; related articles listed above are the flag/submit sources
- confidence: medium
### [9] UI inference: "Flags 0/10" + free-form submit without questions is more consistent with CTF multi-flag Challenge checkpoints than with Labs Sherlock question flow
- quote: "For Challenges that contain multiple flags, XP distribution follows the catalogue below: XP for Checkpoints (only used on CTFs)" combined with CTF flag flexibility ("date, a name, an IP address, or a CVE number") — suggests Holmes CTF SilentDividend may expect bare IOC-like answers rather than HTB{IOC} wrappers.
- url: https://help.hackthebox.com/en/articles/5200851-ctf-user-s-guide
- source_type: primary
- published: Updated yesterday (as of 2026-09-17 fetch)
- confidence: medium
